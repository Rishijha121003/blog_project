# 📝 Blog Project (Django)

A simple **Blog Web Application** built using **Django** where users can create, view, edit, and delete blog posts.

---

## 🚀 Features

* Create blog posts
* Edit existing posts
* Delete posts
* View list of all blog posts
* Individual post detail page
* URL routing for posts

---

## 🛠️ Tech Stack

* **Backend:** Django, Python
* **Frontend:** HTML, CSS
* **Database:** SQLite
* **Tools:** Git, GitHub

## ⚙️ Installation

1. Clone the repository

git clone https://github.com/Rishijha121003/blog_project.git

2. Go into the project folder

cd blog_project

3. Create virtual environment

python -m venv venv

4. Activate virtual environment

Windows
venv\Scripts\activate

Linux / Mac
source venv/bin/activate

5. Install dependencies

pip install -r requirements.txt

6. Run the server

python manage.py runserver
